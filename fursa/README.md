# فرصة · Fursa

فريق صغير من الوكلاء يدوّر على شغل مدفوع (وظائف عن بعد، شغل بالعراق، مشاريع حرة ومهام مدفوعة) لمطوّر **Flutter/Dart** و**Python/Django** بالموصل. يشتغل وحده كل 6 ساعات على GitHub Actions، يحفظ ذاكرته بنفس الريبو، يعرض النتائج بموقع بسيط على [claude.ai](https://claude.ai/artifact/SVapXSt8B5HC3Ua2CMGL8M)، ويرسل الفرص على تلگرام بس لما يلگي شي يستاهل.

> A small team of agents that hunts paid work for one developer, runs on GitHub Actions every 6 hours, keeps its memory as JSON in this repo, and shows everything on a dashboard published as a claude.ai Artifact.

## ليش يصرف tokens قليلة

1. **الكود يسوي الشغل الرخيص**: السحب، حذف المكرر، التقييم بالكلمات، فحص الأهلية والتاريخ والرسوم. هاي كلها 0 tokens.
2. **الذكاء يشوف بس اللي يستاهل**: الكشّاف يفحص أعلى 12 إعلان بكل تشغيل، 6 بالطلب الواحد، ونص مقصوص.
3. **الذاكرة تمنع التكرار**: أي إعلان شافه الفريق ما يرجع يفحصه، وأي فرصة انعرضت عليك ما تنعاد.
4. **المدير القوي مرتين باليوم بس**، طلب واحد يراجع كل المسودات سوا.
5. **سقف شهري**: إذا وصلت الكلفة السقف (افتراضياً 5$)، الفريق يكمل بالوضع المجاني لحد الشهر الجاي.

### الكلفة المتوقعة (تقدير، مو وعد)

| البند | السعر | تقريباً بالشهر |
|---|---|---|
| الكشّاف + المطابق + الكاتب (Haiku 5.5) | $0.10 / $0.50 لكل مليون token | ~ $0.6 |
| المدير (Opus 5.5، جهد low، مرتين باليوم) | $4 / $20 لكل مليون token | ~ $2–3 |
| بحث الويب (4 عمليات باليوم) | $10 لكل 1000 بحث | ~ $1.3 |
| أفكار أسبوعية + وصف المستودعات | | ~ $0.3 |

يعني تقريباً **4–5$ بالشهر**، والسقف يمنع أي زيادة. ويمكن تشغيله **مجاناً 100%** بدون مفتاح: يشتغل بالقواعد والقوالب بس (جودة أقل، وتلگرام بس للفرص القوية، ومراجعة وحدة كل 12 ساعة بحد أقصى 3 فرص).

## التشغيل خطوة بخطوة

1. **الريبو**: [`Thanoon12k/fursa-agents`](https://github.com/Thanoon12k/fursa-agents) (Public: دقائق GitHub Actions مجانية بالريبوهات العامة).
2. **المفاتيح**: بالريبو ← Settings ← Secrets and variables ← Actions ← New repository secret:
   - `ANTHROPIC_API_KEY`: من [console.anthropic.com](https://console.anthropic.com) ← API Keys، مع رصيد بسيط (مثلاً 5$).
   - `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHAT_ID` (اختياري، قسم تلگرام تحت).
   - (اختياري) بتبويب Variables: `RELIEFWEB_APPNAME`، appname مجاني يُطلب من [ReliefWeb](https://apidoc.reliefweb.int/parameters#appname) لوظائف المنظمات بالعراق.
3. **الموقع**: https://claude.ai/artifact/SVapXSt8B5HC3Ua2CMGL8M (خاص، بس صاحب الحساب يفتحه). الصفحة `docs/index.html` والبيانات `docs/data/*.json` تنرفع عليه سوة، والصفحة تقرا البيانات من جنبها. Claude يحدّثه مرتين باليوم (روتين «Fursa dashboard refresh» بحسابك: 06:44 و18:44 بتوقيت العراق، بعد تشغيل الوكلاء. يشتغل بجلسة «Fursa dashboard refresher» على Haiku 5.5، وكل تحديث تقريباً سنت واحد من استخدام حسابك. يتعدّل أو يتوقف من صفحة Routines بـ claude.ai)، وأي وقت ثاني يكفي طلب «حدث الموقع». ماكو GitHub Pages.
4. **أول تشغيل**: تبويب Actions ← *Fursa agents* ← Run workflow. بعدها يشتغل وحده كل 6 ساعات (05:23، 11:23، 17:23، 23:23 بتوقيت العراق).
5. **الإعدادات** بملف `profile.toml`: المهارات، الكلمات وأوزانها، الميزانية، الموديلات، والمصادر.

## تلگرام

**شنو يسوي:**
- لكل فرصة جديدة يعتمدها المدير توصل رسالة: العنوان، الأجر، ليش تناسبك، المشاريع المقترحة، و**المسودة كاملة داخل الرسالة** (تنفتح بالضغط عليها) حتى تنسخها من تلگرام مباشرة، مع زرين: «الإعلان» و«التفاصيل والمسودة».
- **أزرار الإرسال**: «📲 واتساب» (إذا الإعلان بيه رقم، ومنها أرقام العراق 07xx) و«✉️ إيميل» (جيميل جاهز بالعنوان والموضوع والنص) و«💬 تلگرام» (إذا بيه معرّف للتواصل) و«📝 رابط التقديم»، وزر «📤 إرسال المسودة» يفتح قائمة محادثات تلگرام والمسودة جاهزة لأي شخص. كل زر يفتح التطبيق والرسالة مكتوبة؛ **الإرسال بضغطة منك**.
- كل رسالة للزبون أو الشركة بيها **رابط موقعك الشخصي** (من `website` بملف `profile.toml`).
- **الرد على رسالة الفرصة** بكلمة «قدمت» أو «مقابلة» أو «ما تهمني» (أو «انرفضت»، «عرض شغل»، «بعدين») يحفظ الحالة بالذاكرة، والبوت يأكد بالتشغيل الجاي.
- ماكو رسائل فارغة، والرسائل بين 12 بالليل و8 الصبح توصل بدون صوت.
- البوت يقبل الردود بس من محادثتك (`TELEGRAM_CHAT_ID`).
- البوت ما عنده سيرفر: يقرا الرسائل ويجاوب مع كل تشغيل (كل 6 ساعات)، و`/start` أو `/help` يرجّع شرح مختصر.
- الفرص اللي انعتمدت قبل ربط البوت توصل أول ما ينربط (إذا عمرها أقل من أسبوع)، وكل فرصة توصل مرة وحدة بس.

**الربط (5 دقائق):**
1. بتلگرام: [@BotFather](https://t.me/BotFather) ← `/newbot` ← اسم للبوت ← نسخ التوكن.
2. بالريبو: Settings ← Secrets ← Actions ← `TELEGRAM_BOT_TOKEN` = التوكن.
3. إرسال أي رسالة للبوت الجديد بتلگرام.
4. Actions ← **Telegram setup** ← Run workflow ← بسجل التشغيل يطلع `Chat id ...`.
5. حفظ الرقم كـ secret باسم `TELEGRAM_CHAT_ID`، وتشغيل **Telegram setup** مرة ثانية: توصل رسالة تجربة.

## الاستخدام اليومي

1. توصل رسائل تلگرام بيها 1–3 فرص (بس لما يكون أكو شي جديد يستاهل).
2. المسودة موجودة داخل الرسالة، وزر «📄 التفاصيل» يفتح الفرصة نفسها بالموقع.
3. إكمال أي `[حقل ناقص]` ← زر الإرسال المناسب (واتساب، إيميل، تلگرام، أو رابط التقديم) ← مراجعة وإرسال **بنفسك**.
4. الرد على رسالة الفرصة بـ «قدمت» يحفظ الحالة. وبالموقع نفس الشي من أزرار «قدّمت» و«عندي مقابلة» و«ما تهمني».

## الذاكرة المشتركة: ملفات JSON بالريبو لو Supabase؟

الاختيار: **ملفات JSON داخل الريبو** (`docs/data` للموقع و `state` للأشياء الداخلية):

- **الـ tokens نفسها بالحالتين**؛ اللي يقرر عدد الـ tokens هو شكد نبعث للموديل، مو وين نخزن. والكود هنا يحذف المكرر قبل لا يوصل أي شي للذكاء.
- **أدق وأبسط**: كل تشغيل يصير commit، فأكو تاريخ كامل لكل تغيير مجاناً، والرجوع لأي نسخة سهل.
- **صفر إعداد**: ماكو حساب ثاني ولا مفاتيح ولا جداول، والموقع يقرأ نفس الملفات.
- **Supabase يستاهل** إذا صار أكثر من جهة تكتب بنفس الوقت، أو صار مطلوب تعديل من الموقع مباشرة بدون GitHub، أو صارت البيانات بالآلاف. كل التخزين بملف واحد (`fursa/store.py`)، فالتحويل لاحقاً سهل.

## القواعد اللي يلتزم بيها الفريق

- ما يرسل رسائل، ما يقدّم، ما يسوي حسابات، وما يدفع فلوس. كل إرسال يصير منك بنفسك.
- ما يختلق اسم أو رقم أو سنوات خبرة أو شهادات أو رواتب أو نتائج مشاريع. معلوماتك تنكتب بس من `profile.toml`، واللي ناقص يبقى `[حقل]` واضح.
- يقرأ **المستودعات العامة فقط**، ويتأكد من التقنية من الملفات نفسها (pubspec.yaml, requirements.txt) ومن نسبة المساهمة، وما يفترض إن كل مشروع إنتاجي.
- يستبعد الإعلانات المنتهية واللي تطلب رسوم، ويوضح أي شك بالأهلية للمقيم بالعراق.
- **عروض المنصات (مستقل، خمسات، Freelancer، نفذلي) بدون إيميل أو رقم أو واتساب**: المنصات تمنع التواصل الخارجي قبل التوظيف وممكن توقف الحساب؛ العرض بيه روابط المشاريع والموقع الشخصي بس، وما تطلع أزرار تواصل مباشر لمشاريع المنصات.
- يستبعد شغل المبيعات بالعمولة والتقييمات الوهمية وبيع/توثيق الحسابات.
- لينكدإن وفيسبوك وX: نتائج البحث العامة بس؛ تنعلَّم «غير موثّقة» لحد فتح الإعلان الأصلي والتأكد منه.
- ماكو ضمان دخل.

## ملاحظات صادقة

- بحث الويب (لينكدإن/فيسبوك/X) يشتغل بس مع مفتاح Claude.
- **مستقل وخمسات يرفضون سيرفرات GitHub** (HTTP 403، حماية Cloudflare). الفريق ما يتحايل على الحماية: يجرّب RSS مستقل الرسمي، وبحث الويب يدوّر مشاريعهم المفتوحة (`site:mostaql.com/project`)، والسجل بالموقع يبيّن الحالة «blocked». فتح مستقل يدوياً مرة باليوم يبقى مفيد.
- مكافآت GitHub (bounties) تنعرض كـ «غير محسومة» لأن منصات الدفع ممكن ما تدعم العراق.
- GitHub يوقف الجدولة بالريبوهات العامة إذا ما صار أي نشاط 60 يوم. الفريق يسوي commit بكل تشغيل فهذا ما يصير عادةً؛ وإذا توقف، يتفعّل من جديد من تبويب Actions.
- شروط المصادر (Remotive, Remote OK, Jobicy): ذكر المصدر ورابط مباشر للإعلان الأصلي، والموقع يلتزم بهذا.

```bash
python -m fursa run --free     # تشغيل كامل بدون ذكاء (مجاني)
python -m fursa collect        # بس سحب وتقييم
python -m fursa portfolio      # إعادة قراءة المستودعات
python -m fursa telegram-setup # chat id لتلگرام + رسالة تجربة
pip install pytest && python -m pytest -q
```
