# فرصة · Fursa

فريق صغير من الوكلاء يدوّر إلك على شغل مدفوع (وظائف عن بعد، شغل بالعراق، مشاريع حرة ومهام مدفوعة) لمطوّر **Flutter/Dart** و**Python/Django** بالموصل. يشتغل وحده كل 6 ساعات على GitHub Actions، ويحفظ ذاكرته بنفس الريبو، ويعرض النتائج بموقع بسيط، ويبعثلك تلگرام بس لما يلگي شي يستاهل.

> A small team of agents that hunts paid work for one developer, runs on GitHub Actions every 6 hours, keeps its memory as JSON in this repo, and shows everything on a GitHub Pages dashboard.

## ليش يصرف tokens قليلة

1. **الكود يسوي الشغل الرخيص**: السحب، حذف المكرر، التقييم بالكلمات، فحص الأهلية والتاريخ والرسوم. هاي كلها 0 tokens.
2. **الذكاء يشوف بس اللي يستاهل**: الكشّاف يفحص أعلى 12 إعلان بكل تشغيل، 6 بالطلب الواحد، ونص مقصوص.
3. **الذاكرة تمنع التكرار**: أي إعلان شافه الفريق ما يرجع يفحصه، وأي فرصة انعرضت عليك ما تنعاد.
4. **المدير القوي مرتين باليوم بس**، طلب واحد يراجع كل المسودات سوا.
5. **سقف شهري**: إذا وصلت الكلفة السقف (افتراضياً 5$)، الفريق يكمل بالوضع المجاني لحد الشهر الجاي.

### الكلفة المتوقعة (تقدير، مو وعد)

| البند | السعر | تقريباً بالشهر |
|---|---|---|
| الكشّاف + المطابق + الكاتب (Haiku 5.5) | $0.10 / $0.50 لكل مليون token | ~ $0.6 |
| المدير (Opus 5.5، جهد low، مرتين باليوم) | $4 / $20 لكل مليون token | ~ $2–3 |
| بحث الويب (4 عمليات باليوم) | $10 لكل 1000 بحث | ~ $1.3 |
| أفكار أسبوعية + وصف المستودعات | | ~ $0.3 |

يعني تقريباً **4–5$ بالشهر**، والسقف يمنع أي زيادة. تكدر تشغّله **مجاناً 100%** بدون مفتاح: يشتغل بالقواعد والقوالب بس (جودة أقل، وما يرسل تلگرام إلا للفرص القوية).

## التشغيل خطوة بخطوة

1. **سوّي ريبو جديد** باسم `fursa` (Public حتى يشتغل GitHub Pages مجاناً) وحط بيه محتويات هالمجلد.
2. **المفاتيح**: بالريبو ← Settings ← Secrets and variables ← Actions ← New repository secret:
   - `ANTHROPIC_API_KEY`: من [console.anthropic.com](https://console.anthropic.com) ← API Keys (واشحن رصيد بسيط، مثلاً 5$).
   - `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHAT_ID` (اختياري، الخطوة 6).
   - (اختياري) بتبويب Variables: `RELIEFWEB_APPNAME` إذا طلبت appname مجاني من [ReliefWeb](https://apidoc.reliefweb.int/parameters#appname) لوظائف المنظمات بالعراق.
3. **الموقع**: Settings ← Pages ← Source: *Deploy from a branch* ← Branch: `main` ومجلد `/docs` ← Save. الموقع يصير على `https://thanoon12k.github.io/fursa/`.
4. **أول تشغيل**: تبويب Actions ← *Fursa agents* ← Run workflow. بعدها يشتغل وحده كل 6 ساعات (05:23، 11:23، 17:23، 23:23 بتوقيت العراق).
5. **عدّل `profile.toml`** إذا تريد: مهاراتك، الكلمات وأوزانها، الميزانية، الموديلات، والمصادر.
6. **تلگرام** (اختياري):
   1. افتح [@BotFather](https://t.me/BotFather) ← `/newbot` ← خذ التوكن.
   2. ابعث أي رسالة للبوت مالتك.
   3. افتح `https://api.telegram.org/bot<TOKEN>/getUpdates` بالمتصفح وانسخ الرقم اللي بعد `"chat":{"id":`.
   4. حط القيمتين كـ secrets (الخطوة 2).
   الرسائل بين 12 بالليل و8 الصبح تجي بدون صوت.

## الاستخدام اليومي

1. توصلك رسالة تلگرام فيها 1–3 فرص (بس لما يكون أكو شي جديد يستاهل؛ ماكو رسائل فارغة).
2. تفتح رابط «المسودة والتفاصيل» بالموقع: تقرأ ليش تناسبك، المشاريع المقترحة، والمسودة.
3. **نسخ الرسالة** ← تكمّل أي `[حقل ناقص]` مؤشَّر بالأصفر ← تفتحها بجيميل أو واتساب ← تراجعها وترسلها **إنت بنفسك**.
4. تضغط **«قدّمت»** أو **«عندي مقابلة»** أو **«تجاهلها»**: ينفتح Issue جاهز بـ GitHub، تضغط Submit، والحالة تنحفظ بالذاكرة تلقائياً.

## الذاكرة المشتركة: ملفات JSON بالريبو لو Supabase؟

اخترنا **ملفات JSON داخل الريبو** (`docs/data` للموقع و `state` للأشياء الداخلية):

- **الـ tokens نفسها بالحالتين**؛ اللي يقرر عدد الـ tokens هو شكد نبعث للموديل، مو وين نخزن. والكود هنا يحذف المكرر قبل لا يوصل أي شي للذكاء.
- **أدق وأبسط**: كل تشغيل يصير commit، فعندك تاريخ كامل لكل تغيير مجاناً، وتگدر ترجع لأي نسخة.
- **صفر إعداد**: ماكو حساب ثاني ولا مفاتيح ولا جداول، والموقع يقرأ نفس الملفات.
- **Supabase يستاهل** إذا صار أكثر من شخص يكتب بنفس الوقت، أو تريد تعدّل من الموقع مباشرة بدون GitHub، أو صارت البيانات بالآلاف. كل التخزين بملف واحد (`fursa/store.py`)، فالتحويل لاحقاً سهل.

## القواعد اللي يلتزم بيها الفريق

- ما يرسل رسائل، ما يقدّم، ما يسوي حسابات، وما يدفع فلوس. كل إرسال تسويه إنت.
- ما يختلق اسم أو رقم أو سنوات خبرة أو شهادات أو رواتب أو نتائج مشاريع. معلوماتك تنكتب بس من `profile.toml`، واللي ناقص يبقى `[حقل]` واضح.
- يقرأ **مستودعاتك العامة فقط**، ويتأكد من التقنية من الملفات نفسها (pubspec.yaml, requirements.txt) ومن نسبة مساهمتك، وما يفترض إن كل مشروع إنتاجي.
- يستبعد الإعلانات المنتهية واللي تطلب رسوم، ويوضح أي شك بالأهلية للمقيم بالعراق.
- لينكدإن وفيسبوك وX: نتائج البحث العامة بس؛ تنعلَّم «غير موثّقة» لحد ما تفتح الإعلان الأصلي بنفسك.
- ماكو ضمان دخل.

## ملاحظات صادقة

- بحث الويب (لينكدإن/فيسبوك/X) يشتغل بس مع مفتاح Claude.
- مكافآت GitHub (bounties) تنعرض كـ «غير محسومة» لأن منصات الدفع ممكن ما تدعم العراق.
- GitHub يوقف الجدولة بالريبوهات العامة إذا ما صار أي نشاط 60 يوم. الفريق يسوي commit بكل تشغيل فهذا ما يصير عادةً؛ وإذا توقف، فعّله من تبويب Actions.
- شروط المصادر (Remotive, Remote OK, Jobicy): ذكر المصدر ورابط مباشر للإعلان الأصلي، والموقع يسوي هالشي.

## للمطوّرين

```bash
pip install -r requirements.txt
python -m fursa run --free     # تشغيل كامل بدون ذكاء (مجاني)
python -m fursa collect        # بس سحب وتقييم
python -m fursa portfolio      # إعادة قراءة مستودعاتك
python -m fursa telegram-test  # رسالة تجربة لتلگرام
pip install pytest && python -m pytest -q
```
